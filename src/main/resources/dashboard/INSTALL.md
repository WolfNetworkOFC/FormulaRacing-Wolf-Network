# FormulaRacing Dashboard - Installation

The dashboard is served automatically by the plugin's embedded web server.

## Access
Open `http://<server-ip>:<port>/dashboard/` in your browser (default port 10003).

## Files
- `index.html` - main dashboard
- `live-map.html` - live map view
- `css/` - stylesheets
- `js/` - scripts

No manual installation is required.
