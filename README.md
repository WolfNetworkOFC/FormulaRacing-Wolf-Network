# 🏎️ Formula Racing - Wolf Network

Plugin de Minecraft para corridas de barco desenvolvido para o servidor Wolf Network.

## 📋 Características

- 🏁 Sistema de corridas competitivas
- ⚔️ Duelos 1v1 entre jogadores
- 🎯 Modo Time Trial
- 📊 Leaderboards por pista
- 🎨 Sistema de cosméticos
- 🌍 Multilinguagem (PT-BR, PT-PT, EN-US)
- 🎪 Eventos automáticos
- 📱 GUI moderna

## 🛠️ Requisitos

- Java 17+
- Spigot/Paper 1.21.8+
- WorldEdit
- DecentHolograms

## 🔧 Compilação

```bash
mvn clean package
```

O arquivo `.jar` estará em `target/formularacing-0.2.jar`

## 📖 Comandos Principais

| Comando | Descrição |
|---------|-----------|
| `/fr` | Menu principal |
| `/fr reload` | Recarregar plugin |
| `/fr language <lang>` | Trocar idioma |
| `/duel <player>` | Desafiar jogador |
| `/event` | Gerenciar eventos |
